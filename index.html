¿Dónde consigo clave gratis?
  • OpenRouter: openrouter.ai → Keys. Modelo free: nvidia/nemotron-3-ultra-550b-a55b:free
  • Groq: console.groq.com → API Keys. Rápido, sin tarjeta.
  • Gemini: aistudio.google.com → Get API Key. Cuota gratuita.
  • NVIDIA: build.nvidia.com → API Key. ~40 RPM gratis.
